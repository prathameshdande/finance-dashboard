#  Finance Dashboard UI

##  Features
- Dashboard overview (Balance, Income, Expenses)
- Charts (Trend + Category breakdown)
- Transactions with search/filter
- Role-based UI (Viewer/Admin)
- Insights section
- LocalStorage persistence

## Tech Stack
- React (Vite)
- Tailwind CSS
- Recharts
- Context API

## Setup
npm install
npm run dev

## Approach
- Modular components
- Clean UI
- Context API for state
- Mock data used
